# 局内状态提示修复与验收

更新时间：2026-10-09。本轮仅推进显示正确性与有限避让，没有生成素材、修改战斗规则或上线。

## 修复

- 引擎的 `slow` 是速度倍率，`1` 表示正常；旧显示条件 `slow>0` 将正常敌人错误标为减速，并挡住了击退提示。现在仅 `0<slow<1` 显示“慢”，不读取下一帧的 `nextSlow`。
- 眩晕、燃烧、流血、减速、击退分别用“晕/燃/血/慢/退”小标记；一次只显示最高优先状态。兼容显式状态文本，Boss身份不重复当状态显示。
- 状态牌每帧最多12个，优先Boss/精英；依原深度顺序，尝试原位、上移19/38单位，牌之间保留3单位间距，避开玩家包围盒及画布边界。位置不足时隐藏提示，不清除实际状态。
- 普通虎妖血条固定在 `y-3.05r`，不随动作抖动；移除额外眩晕星环，避免头顶重复提示。32姿态×4种半径的裁切包围检查通过。
- 槽位仅保留最多12个纯数字矩形并复用，dispose时清空；没有修改引擎伤害、移动、状态时钟、RNG或素材像素。
